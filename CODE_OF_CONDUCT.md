# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be kind and respectful. No harassment, insults or personal attacks.

Report unacceptable behavior to contact@royan.se. Reports stay confidential.
The maintainers may remove comments, code or contributors that break these
rules.
