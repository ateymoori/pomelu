# Security policy

## Report a vulnerability

Do not open a public issue for a security problem. Use
[private vulnerability reporting](https://github.com/ateymoori/pomelu/security/advisories/new)
on GitHub, or email contact@royan.se.

Tell us the version (Settings → About), the platform, the steps, and the
impact. We reply within 7 days and tell you when the fix ships.

## Scope

- In scope: this app (Android and iOS), how it stores the gateway sign-in,
  how it talks to the gateway, the share extension, deep links and the
  Bot Screen viewer.
- Out of scope: Hermes Agent itself (report to
  [Nous Research](https://github.com/NousResearch/hermes-agent/security)),
  and a gateway that you expose to the internet without a password or HTTPS.

## Supported versions

Only the newest release in the App Store and Google Play gets fixes.
